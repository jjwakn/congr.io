# Security Policy

The security of this project is extremely important, especially since it may store personal information of church members.

## Reporting a Vulnerability

If you discover a security vulnerability, please DO NOT open a public issue.

Instead, email:

jjwakn@gmail.com

Include:

- A detailed description of the issue
- Steps to reproduce (if possible)
- Potential impact
- Any suggested fix (optional)

We will:

- Acknowledge receipt within 72 hours
- Investigate promptly
- Release a patch if confirmed

## Supported Versions

Only the latest stable version is actively maintained.

## Responsible Disclosure

Please allow reasonable time for a fix before publicly disclosing vulnerabilities.
