# Código de Conducta

Nos comprometemos a proporcionar un entorno amable, seguro y acogedor para todas las personas.

## Nuestros Estándares

Ejemplos de comportamiento que contribuye a un entorno positivo:

- Ser respetuoso y constructivo
- Asumir buena intención
- Aceptar la retroalimentación con apertura
- Enfocarse en lo mejor para la comunidad y los usuarios

El comportamiento inaceptable incluye:

- Acoso, discriminación o discurso de odio
- Ataques personales o trolling
- Publicar información privada sin consentimiento
- Cualquier comportamiento que cree un entorno inseguro

## Alcance

Esto aplica a todos los espacios del proyecto (issues, PRs, discusiones de GitHub y canales de comunidad).

## Aplicación

Las personas mantenedoras del proyecto pueden eliminar, editar o rechazar comentarios, commits, issues o PRs que violen este Código de Conducta.
