## 📌 Frontend – `congr.io`

This is the **frontend** for the `congr.io` platform, built with:

- ⚡ [Vite](https://vitejs.dev/) – Lightning-fast build tool
- ⚛️ [React](https://react.dev/) – Component-based UI library
- 🎨 [Material UI (MUI)](https://mui.com/) – UI components & theming
- 📱 [PWA](https://vite-pwa-org.netlify.app/) support via `@vite-pwa/plugin`
- 🌎 i18n support for multilingual UI
- 🔄 API integration with our backend (`http://localhost:4000` in dev)

---

## 📱 PWA Support

This project is a **Progressive Web App**.

- **Auto-updates** in the background
- Works offline with cached assets
- Installs on mobile & desktop
- Supports push notifications (optional)
