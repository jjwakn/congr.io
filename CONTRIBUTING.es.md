# Contribuir

Gracias por ayudar a mejorar este proyecto. Este repositorio es un monorepo (`web` + `api`).

## Inicio Rápido (Desarrollo Local)

Si el README tiene pasos más actualizados, sigue primero el [README](./README.es.md).

## Formas De Contribuir

- Corregir errores
- Agregar pruebas
- Mejorar la documentación (guías de despliegue, arquitectura, capturas)
- Agregar un módulo de funcionalidad
- Mejorar accesibilidad y traducciones

## Convenciones Del Proyecto

### Ramas

- Crea ramas desde `main`
- Nombre: `feat/<short-name>`
- Nombre: `fix/<short-name>`
- Nombre: `docs/<short-name>`
- Nombre: `chore/<short-name>`

### Commits

Aplicamos Conventional Commits:

- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
- `refactor: ...`
- `test: ...`

### Pull Requests

Incluye:

- Qué cambió y por qué
- Capturas o GIFs para cambios de UI
- Cómo probarlo localmente
- Notas de migración (si aplica)

## Estilo De Código

Ejecuta formato/lint antes de abrir un PR (si está configurado):

- `yarn lint`
- `yarn format`

## Reporte De Problemas De Seguridad

Por favor no abras issues públicos para vulnerabilidades de seguridad.
Consulta `SECURITY.md` para el proceso de reporte.

## Licencia / Contribuciones

Al enviar una contribución, aceptas que tu contribución se licencia bajo la licencia de este proyecto.
