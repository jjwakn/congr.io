# Contributing

Thanks for helping improve this project. This repository is a monorepo (`web` + `api`).

## Quick Start (Local Dev)

If the README has more up-to-date steps, follow the [README](./README.en.md) first.

## Ways To Contribute

- Fix bugs
- Add tests
- Improve docs (deploy guides, architecture, screenshots)
- Add a feature module
- Improve accessibility and translations

## Project Conventions

### Branches

- Create branches from `main`
- Naming: `feat/<short-name>`
- Naming: `fix/<short-name>`
- Naming: `docs/<short-name>`
- Naming: `chore/<short-name>`

### Commits

We enforce Conventional Commits:

- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
- `refactor: ...`
- `test: ...`

### Pull Requests

Please include:

- What changed and why
- Screenshots or GIFs for UI changes
- How to test locally
- Any migration notes (if applicable)

## Code Style

Run formatting/linting before opening a PR (if configured):

- `yarn lint`
- `yarn format`

## Reporting Security Issues

Please do not open public issues for security vulnerabilities.
See `SECURITY.md` for the reporting process.
